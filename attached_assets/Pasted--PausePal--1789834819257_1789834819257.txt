## 三个人共同遵守的接口

技术栈：Python FastAPI + 原生 HTML/CSS/JavaScript，一个服务提供网页和 API，不添加数据库或登录。

POST /api/analyze

请求示例：

```json
{"text":"Grandma, send me $900 now. Do not tell Mom."}
```

响应结构示例（不是已运行结果）：

```json
{
  "assessment": "warning",
  "summary": "Pause and verify this request using a contact you already trust.",
  "signals": [
    {"quote": "send me $900 now", "reason": "Urgent request for money"},
    {"quote": "Do not tell Mom", "reason": "Request for secrecy"}
  ],
  "next_steps": [
    "Pause before taking action.",
    "Contact the person using a number saved before this message arrived."
  ],
  "mode": "live"
}
```

- assessment 只允许 warning、no_clear_signals、insufficient_information。没有明显线索不等于安全。
- summary、reason、next_steps 和错误提示全部英文；quote 必须为输入中的连续原文，后端校验。
- 只接收非空、去掉首尾空白后 1–4000 字符的 text。无效输入返回 422；模型不可用返回 503，detail 为清楚的英文提示。
- mode 仅 live / demo；真实模型失败不能偷偷返回模拟成功。
- 前端安全渲染用户文本与模型输出，不能把这些内容当 HTML 执行。
- 联系人不发给模型，只由核实页面管理。没有自动发送消息、自动拨号或自动确认成功。
