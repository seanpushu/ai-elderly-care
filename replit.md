# PausePal shared starter

Use FastAPI and plain HTML/CSS/JavaScript. Start with `python start.py` after installing `requirements.txt`. Keep the English product and the existing API contract. Analysis is currently an explicitly labeled demo; live AI integration is a teammate's next task.

Before changes, check the current branch and git status. Preserve existing work. Never reset or force-push. Respect the file ownership in README.md. Importing a repo does not automatically pull future GitHub changes.

frontend owns static/index.html, static/analyze.js, static/analyze.css. backend-ai owns app/, dependencies, tests, and startup configuration. integration owns static/verify.html, static/verify.js, static/verify.css and release coordination. main is the published version.

No database, account system, automatic messaging, or real-time call interception. No safety guarantees or invented test results. Source quotes are exact substrings; all generated explanations remain English.
